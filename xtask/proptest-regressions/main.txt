# Seeds for failure cases proptest has generated in the past. It is
# automatically read and these particular cases re-run before any
# novel cases are generated.
#
# It is recommended to check this file in to source control so that
# everyone who runs the test benefits from these saved cases.
#
# The three seeds previously stored here were all the same class of malformed
# input — a `type` member whose array holds a non-string (`[null]`, `[false]`,
# `[[]]`). They were recorded before `any_document` was meant to exclude such
# documents, and because the exclusion was incomplete they kept replaying, so
# `the_downgrade_is_idempotent` was red on a random schedule. `any_document` now
# generates `type` from a dedicated well-formed strategy, and the non-idempotence
# on malformed input is pinned directly by
# `a_non_string_type_member_is_not_idempotent`. Replaying values the strategy can
# no longer produce would only re-assert that known edge as a failure.
